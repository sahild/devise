# Devise + DynamoDB sample app

A minimal Rails 8.1 app that stores its `User` model in Amazon DynamoDB and
enables all seven modules the DynamoDB adapter supports:
`database_authenticatable`, `registerable`, `recoverable`, `rememberable`,
`validatable`, `confirmable`, `trackable` and `lockable`.

It runs with either library:

| `DYNAMODB_LIBRARY` | Model |
|---|---|
| `dynamoid` (default) | `app/models/dynamoid/user.rb` |
| `aws_record` | `app/models/aws_record/user.rb` |

Both models were created with Devise's generators
(`rails g dynamoid:devise User` and `rails g aws_record:devise User`) and edited
only to enable all modules and token indexes.

## Running it

```console
docker run -d -p 8000:8000 amazon/dynamodb-local   # or any DynamoDB Local

cd examples/dynamodb_app
bundle install
bin/rails devise:dynamodb:ping
bin/rails devise:dynamodb:create_tables
bin/rails server
```

For aws-record, prefix every command with `DYNAMODB_LIBRARY=aws_record`.

Then sign up at http://localhost:3000/users/sign_up. Emails use the `:test`
delivery method, so confirmation, unlock and reset links appear in the server log.

To use real AWS instead of DynamoDB Local, set `DYNAMODB_ENDPOINT=""` and your
usual `AWS_REGION` / credentials (see `config/initializers/dynamodb.rb`).

## Tests

```console
bin/rails test
DYNAMODB_LIBRARY=aws_record bin/rails test
```

`test/integration/user_flows_test.rb` covers sign up and confirmation,
case-insensitive email uniqueness, tracking, locking and unlocking, password
reset, remember me and email reconfirmation.

## Files of interest

* `config/initializers/devise.rb` — `config.dynamodb_library` + `require 'devise/orm/dynamodb'`
  (generated by `rails g devise:install --orm=dynamodb`)
* `config/initializers/dynamodb.rb` — connection settings for both libraries
* `config/application.rb` — `g.orm :dynamodb`, so `rails g devise MODEL` uses the DynamoDB generators

See [the DynamoDB guide](../../guides/dynamodb.md) for details and limitations.
